Le Défi Hydrique dans la Région du Souss-Massa

Contexte Global
🔥 85% de l'Eau Douce Consommée par l'Agriculture

Le Souss-Massa (Taroudant/Agadir : 30.42°N, 8.87°W) fournit la majorité des agrumes et primeurs du Maroc, mais fait face à un abaissement critique des nappes phréatiques (Chtouka).

🏜️ Épisodes Aigus de Chergui

Vents brûlants du désert dépassant 40°C avec une humidité de l'air < 15%. L'évapotranspiration explose à plus de 9 mm/jour, asphyxiant les cultures sans adaptation immédiate.

⏱️ L'Échec des Minuteries Classiques (Fixed-Timers)
  • Arrosage aveugle : arrose même après la pluie ou si le sol est saturé.
  • Gaspillage d'eau : estimé à plus de 30% des volumes pompés.
  • Zéro sécurité : si le capteur est cassé, la pompe noie le champ.
💡 La Réponse : Edge AI Déterministe

Une décision d'irrigation locale, instantanée (0.18 µs), calculée directement dans le microcontrôleur STM32 à partir de l'évapotranspiration réelle, avec coupure de sécurité matérielle (Watchdog 30s).

📐 Évapotranspiration FAO-56 Penman-Monteith

Standard mondial calculant la perte d'eau en mm/jour selon le vent, rayonnement solaire et déficit de vapeur :

ET₀ = [ 0.408·Δ·(Rn - G) + γ·(900/(T+273))·u₂·(es - ea) ] / [ Δ + γ·(1 + 0.34·u₂) ]

Répartition Réelle du Climat du Souss (731 Jours)

Jours avec Arrosage Requis (Sécheresse / ET₀ élevé) 633 j (86.6%)
Jours de Repos (Pluies hivernales / faible ET₀) 98 j (13.4%)
💡 Règle de Décision Agronomique : Le besoin net d'irrigation est formulé par I_net = max(0, Kc × ET₀ - P_eff) avec un coefficient cultural Kc = 0.85.

// Inférence C pur sans allocation dynamique
static inline uint8_t tinyml_predict_irrigation(
  float temp_c, float humidity,
  float et0_mm, float soil_raw) {

  if (soil_raw <= 2200.0f) {
    if (et0_mm > 3.2f || temp_c > 28.0f)
      return 1; // POMPE ON
    return (humidity < 40.0f) ? 1 : 0;
  } else {
    if (et0_mm > 7.0f && humidity < 25.0f)
      return 1; // CHERGUI
    return 0; // REPOS
  }
}
