La Soif des Cultures dans la Plaine du Souss-Massa

Déficit Hydrique Critique
🌡️ Le Grenier Agricole face au Stress Hydrique

Le bassin du Souss (30.42°N, -8.87°W) concentre l'essentiel des cultures maraîchères (tomates, primeurs) et vergers d'agrumes. Les nappes souterraines (Chtouka) s'épuisent rapidement face à une pluviométrie souvent inférieure à 200 mm/an.

💨 Le Chergui : L'Asphyxie Météorologique

Vent sec et brûlant du Sahara ($T > 40^\circ\text{C}$, Humidité $< 15\%$). L'évaporation s'envole au-delà de 9 mm/jour : sans réaction immédiate de l'arrosage, la récolte est perdue.

⏳ L'Absurdité des Minuteries Horaires Classiques
  • Arrosage aveugle : pompage à heure fixe même s'il a plu la veille.
  • Gaspillage massif : 30 à 40% de l'eau pompée s'évapore inutilement.
  • Risque d'asphyxie : en cas de tuyau bouché ou capteur défectueux, inondation des racines.
🌱 Notre Approche : Agro-Edge Frugal

Un microcontrôleur autonome calcule la soif réelle de la plante en 0.183 µs directement au pied de la parcelle, sans dépendance au réseau Internet et avec coupe-circuit anti-inondation.

📐 Formule FAO-56 Penman-Monteith

Le standard agronomique pour quantifier les pertes d'eau par évapotranspiration :

ET₀ = [ 0.408·Δ·(Rn - G) + γ·(900/(T+273))·u₂·(es - ea) ] / [ Δ + γ·(1 + 0.34·u₂) ]

// Inférence C pur sans allocation dynamique
static inline uint8_t tinyml_predict_irrigation(
  float temp_c, float humidity,
  float et0_mm, float soil_raw) {

  if (soil_raw <= 2200.0f) {
    if (et0_mm > 3.2f || temp_c > 28.0f)
      return 1; // POMPE ON
    return (humidity < 40.0f) ? 1 : 0;
  } else {
    if (et0_mm > 7.0f && humidity < 25.0f)
      return 1; // CHERGUI EXTRÊME
    return 0; // REPOS
  }
}
