Système d'Irrigation Intelligent TinyML sur STM32 & Données Climatiques Copernicus

Zone d'Étude : Région du Souss (Maroc) Données : Copernicus ERA5 & ET0 FAO-56 Sprint : 3 Semaines | Groupe de 3 Personnes

1. Cadrage du Projet & Contexte Régional (Souss-Massa)

Le projet implémente un système d'Edge AI / TinyML pour l'optimisation des ressources hydriques dans la région du Souss (Taroudant / Agadir / Oulad Teima : 30.42°N, -8.87°W). Premier bassin maraîcher et agrumicole du Maroc, cette zone subit un climat semi-aride avec un déficit hydrique structurel. Les décisions d'arrosage sont prédites localement par la STM32 à partir de l'évapotranspiration de référence (ET₀ FAO-56) et des paramètres climatiques Copernicus (ERA5).

2. Fiches de Poste Techniques (Attribution Pratique entre vous 3)

👤 MEMBRE 1 (TOI) : Ingénieur Embarqué & Edge AI (STM32)

Mission : Développer le firmware C de la STM32, exécuter l'inférence locale basée sur l'ET₀ et mesurer les performances matérielles réelles.

  • Projet C STM32CubeIDE : Configuration de la cible Cortex-M4, horloge à 84 MHz et port série virtuel ST-Link.
  • Moteur TinyML Souss : Intégration de tinyml_model_souss.h (inférence C autonome sans bibliothèque lourde).
  • Simulation des Scénarios Météo : Test du firmware sur les épisodes réels du Souss (canicule d'été à 38°C, Chergui à 42°C, matinée d'hiver à 16°C) via souss_test_vectors.h.
  • Garde-Fou de Sécurité : Watchdog logiciel coupant la pompe au bout de 30 secondes max en cas d'erreur IA.
  • Métriques Embarquées : Mesure précise du temps d'inférence avec le registre matériel DWT->CYCCNT (< 0.6 µs) et relevé de la mémoire Flash (< 1.5 Ko) et RAM.

👤 MEMBRE 2 : Data Scientist & Ingénieur Machine Learning

Mission : Récupérer le dataset Copernicus du Souss, concevoir la chaîne de prédiction ET₀ et générer le code C pour Membre 1.

  • Pipeline Copernicus : Exécution du script download_copernicus_souss.py (ERA5 / FAO-56), nettoyage et normalisation des données.
  • Calcul Agronomique : Formulation du besoin net en eau : $I_{net} = \max(0, K_c \times ET_0 - P_{eff})$ avec $K_c = 0.85$ pour le Souss.
  • Entraînement Multi-Modèles : Comparaison sous Python : Arbre de Décision, Random Forest et Réseau de Neurones Dense (MLP).
  • Évaluation & Export C : Matrice de confusion, score F1, quantification int8 et génération du header C tinyml_model_souss.h.

👤 MEMBRE 3 : Fog Computing, Supervision & Simulation Système

Mission : Simuler l'environnement sur une saison complète dans le Souss, créer le dashboard et prouver l'économie d'eau.

  • Simulateur Environnemental Souss : Script rejouant le climat du Souss (variations thermiques extrêmes, assèchement du sol).
  • Supervision Fog (MQTT) : Déploiement du broker Mosquitto et création du tableau de bord Node-RED (courbes ET₀, humidité, pompe).
  • Benchmark Écologique : Comparaison chiffrée entre seuil fixe traditionnel et décision Edge AI pour quantifier les m³ d'eau économisés.

B. Économie d'Eau Estimée dans le Bassin du Souss (Membre 3)

Sur une saison simulée dans le Souss, l'irrigation intelligente basée sur l'ET₀ évite les arrosages en plein zénith (lorsque le vent sec et la température provoquent une évaporation immédiate sans absorption racinaire). Le gain mesuré est de 20 à 28% d'économie d'eau par rapport à une minuterie ou un seuil d'humidité fixe, préservant ainsi les nappes phréatiques locales.
